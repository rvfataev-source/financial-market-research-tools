# Financial Market Research Tools

Experimental Python tools for cryptocurrency market research, data collection, backtesting, and automation.

## Overview

This repository documents my work on building and testing automated tools for financial market research.

Focus areas include:

- Cryptocurrency market data collection through exchange APIs
- Historical data processing and analysis
- Automated backtesting of trading hypotheses
- Technical indicator and signal testing
- Performance analysis using win rate, drawdown, profit factor, and other metrics
- Risk and leverage analysis
- Monitoring of exchange announcements and market events
- AI-assisted development and research automation

## Tech

Python · APIs · Data Analysis · AI-Assisted Development · Automation

## Purpose

The goal of these projects is to reduce manual research, test ideas systematically, and turn market data into structured, measurable results.

> This repository is intended for research and educational purposes only. It does not provide financial advice.
